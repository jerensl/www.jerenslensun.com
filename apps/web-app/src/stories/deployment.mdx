# Introduction

This guide is about deployment related documentation

## Vercel

The website is deployed on [Vercel](https://vercel.com/) and deploys automatically from the `main` branch. Preview deployments are created for every pull request.

Build settings:

-   **Root directory:** `apps/web-app`
-   **Build command:** `pnpm build`
-   **Output directory:** `out`

The production domain is `https://jerensl.dev`.

## Storybook

Component documentation is built with Storybook and published to GitHub Pages by the `Docs Deployment` workflow.
