Hai semuanya! Saya ingin berbagi pengalaman saya sebagai intern pada Proyek Servo melalui Program Outreachy.

Servo adalah mesin peramban web eksperimental yang awalnya dikembangkan oleh Mozilla. Ia ditulis dalam Rust, bahasa pemrograman sistem yang berfokus pada keamanan dan performa. Servo mengeksplorasi arsitektur generasi berikutnya untuk mesin rendering, memanfaatkan jaminan keamanan memori Rust untuk meningkatkan keamanan dan kecepatan. Saat ini, Servo adalah proyek yang digerakkan komunitas di bawah Linux Foundation, melanjutkan misinya untuk mendorong batas teknologi peramban.

Saya beruntung terpilih sebagai intern untuk proyek berjudul **"Meningkatkan code linting di CI Servo."** Pekerjaan saya berfokus pada peningkatan alur kerja GitHub Actions dan meningkatkan _mach_, alat baris perintah Servo yang menyederhanakan tugas seperti membangun, menguji, dan melakukan linting pada proyek.

## Tujuan Proyek

Tujuan utama proyek ini adalah meningkatkan developer experience secara keseluruhan, terutama bagi kontributor yang menggunakan GitHub dan CLI `mach`. Dengan menyederhanakan umpan balik linting dan mengotomatiskan tugas umum, proyek ini bertujuan membuat kontribusi ke Servo lebih mudah, lebih cepat, dan lebih andal.

## Apa yang Paling Membuat Saya Bersemangat tentang Proyek Ini?

Yang paling membuat saya bersemangat adalah dapat bekerja begitu dekat dengan inti cara web bekerja. Mesin peramban sangat terhubung dengan standar dan spesifikasi web, dan bekerja dengan Servo memberi saya kesempatan melihat di balik layar bagaimana Web API—hal yang kita gunakan setiap hari—sebenarnya diimplementasikan pada tingkat mesin rendering. Sangat menarik untuk melihat di balik kap mesin dan memahami bagaimana peramban menafsirkan dan menampilkan web.

## Sekilas Tentang Ekosistem Web

Standar web (seperti yang didefinisikan oleh W3C dan WHATWG) menjelaskan bagaimana web seharusnya bekerja dan berfungsi—mulai dari tata letak dan styling hingga API dan perilaku. Mesin peramban seperti Servo, Gecko milik Firefox, atau Blink milik Chromium mengimplementasikan standar-standar ini. Untuk memastikan mereka melakukannya dengan benar, proyek **Web Platform Tests (WPT)** menyediakan rangkaian pengujian bersama yang dapat dijalankan semua mesin peramban. Pengujian ini kemudian membantu memverifikasi bahwa implementasi berperilaku konsisten di seluruh peramban, meningkatkan kompatibilitas dan mengurangi fragmentasi. Servo mengintegrasikan pengujian ini untuk tetap selaras dengan standar yang terus berkembang.
