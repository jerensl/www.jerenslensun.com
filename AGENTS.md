# AGENTS.md

## Repo shape
- pnpm workspace (`pnpm-workspace.yaml`): `apps/*`, `packages/*`. Only app is `apps/web-app` (Next.js 16, React 19). `packages/` is empty.
- Single app is a statically exported portfolio site (`output: 'export'`, `trailingSlash: true`); output goes to `apps/web-app/out/`. No server runtime.
- Content is MDX in `apps/web-app/contents/{blog,project}` plus images in `contents/images`. Loaded at build time via `fs` with `process.cwd()` = `apps/web-app`, so run build/test from that directory (or via the pnpm filter).

## Environment / setup
- Node 20 required (`.nvmrc` = `lts/iron`; CI uses `node-version-file`). Local default here may be newer; switch with nvm: `nvm use` (or `PATH=.../v20.19.5/bin`).
- pnpm 10.4.1 (`packageManager`). `pnpm install` from repo root.
- `.envrc` sets `NEXT_PUBLIC_API_MOCKING=True` (direnv). Without it, dev mode runs without MSW mocks. For image blur placeholders set `NEXT_PUBLIC_IMAGES_CDN=https://ik.imagekit.io/jerensl` (CI does this; unset falls back gracefully but skips placeholders).
- Other public env vars: `NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_FCM_VAPID_KEY`, `NEXT_PUBLIC_GTM_ID` (defaults to `GTM-PKW49NT`).

## Commands (run from repo root unless noted)
- Dev server: `pnpm --filter "./apps/web-app" dev` (port 3000).
- Serve built site: `pnpm --filter "./apps/web-app" start` (`serve ./out/`).
- Build (static export + sitemap postbuild): `pnpm --filter "./apps/web-app" build`.
- Storybook: `pnpm --filter "./apps/web-app" storybook` (port 6006); build docs: `build:storybook`.
- Lint: `pnpm --filter "./apps/web-app" lint` (eslint 10 flat config); autofix: `lint:fix`.
- Typecheck: `pnpm --filter "./apps/web-app" type-check`.
- Tests: `pnpm --filter "./apps/web-app" test` (Jest + SWC, ESM via `--experimental-vm-modules`). Single file: `... test -- __tests__/libs/tags.test.ts`. Filter by name: `... test -- -t "pattern"`. Watch: `test:watch`. Coverage: `test:coverage`.
- E2E: from `apps/web-app`, `npx playwright test` (config auto-starts app via `pnpm dev`/`pnpm build && pnpm start` on CI). UI mode: `npx playwright test --ui`.

## Verification order
- CI runs build, lint, type-check, unit tests, then Playwright E2E on PRs to `main`. Match locally: lint → type-check → test before pushing.

## Architecture notes
- Path alias `@/*` → `src/*`.
- Pages in `src/pages` (Next.js Pages Router). MDX rendering via `mdx-bundler` with remark/rehype plugins in `src/libs/content.ts` and `src/libs/mdx-plugins/`.
- Content language: filename prefix `en-`/`id-` (see `src/libs/localization.ts` `detectLanguageFromSlug`) unless frontmatter `language` overrides. Only posts with `isPublished: true` are listed.
- Images use a custom loader `src/constant/images.ts` (imagekit CDN) configured in `next.config.mjs`.
- MSW mocks in `src/mocks` (browser + node server); worker dir `public` (gitignored, regenerated by msw).
- PWA via `next-pwa`; service worker custom dir `src/worker`; generated `public/sw.js` and `workbox-*.js` are gitignored.
- Styling: Tailwind v4 + Stitches (`stitches.config.ts`). Design tokens in `tailwind.config.ts`.

## Testing quirks
- Custom Jest environment `jest.environment.cjs` (`FixedTypedArrayJSDOMEnvironment`) aligns typed arrays/Buffer with Node so `esbuild` (used by mdx-bundler) works under jsdom. Do not remove without reason.
- `testPathIgnorePatterns` excludes `node_modules`, `.next`, `cypress`, `e2e`.
- ESLint ignores `__tests__`, `__mocks__`, `public`, `storybook-static`, etc., so tests are not linted.
- 19 test suites / 69 tests baseline; 6 snapshots.

## Git / release
- Conventional Commits enforced by commitlint (`commitlint.config.cts`); allowed types include `blog`, `translation`, `security`, `changeset`. Scope must be lower-case; subject no trailing period; header ≤100 chars.
- Pre-commit: gitleaks, eslint, trailing-whitespace/end-of-file fixers.
- Release Please on `main` (`release-please-config.json`); CHANGELOG at root.
- Default branch `main`; CI triggers on PRs to `main`.

## Gotchas
- `start` serves a prebuilt `out/`; for development use `dev`.
- README's "Start the application" uses `start` but describes dev mode — use `dev`.
- Build needs network for image blur placeholders (imagekit) and mdx; failures are caught but placeholders drop.
- Generated artifacts (`out/`, `.next/`, `coverage/`, `storybook-static/`, `public/sw.js`, `workbox-*.js`) are gitignored — do not commit.

## Bot-authored PRs (GitHub App, Option A)
AI contributions are published under a dedicated GitHub App so they are distinguishable
from human PRs in GitHub's PR list.

Setup (one-time, in GitHub UI):
1. Create a GitHub App (Settings → Developer settings → GitHub Apps):
   - Name e.g. `jerensl-opencode` (bot login becomes `jerensl-opencode[bot]`).
   - Disable the webhook (uncheck "Active"); homepage = repo URL.
   - Repo permissions: Contents R/W, Pull requests R/W, Metadata R.
   - "Where can this GitHub App be installed?" → Only this account.
   - Generate + download the private key (`.pem`); note the App ID.
2. Install the app on `jerensl/www.jerenslensun.com`; note the Installation ID.
3. Store credentials in the local, gitignored `.envrc`:
   ```sh
   export GITHUB_APP_ID=<app-id>
   export GITHUB_APP_INSTALLATION_ID=<installation-id>
   export GITHUB_APP_PRIVATE_KEY=/home/jerensl/.secrets/jerensl-opencode.pem
   export GITHUB_APP_SLUG=jerensl-opencode
   ```

Usage:
- `eval "$(scripts/bot-env.sh)"` exports `GH_TOKEN` + bot git identity.
- `scripts/bot-git push origin <branch>` and `scripts/bot-gh pr create …`.
  (`bot-git` rewrites an SSH `origin` to an HTTPS URL carrying the bot token, so pushes
  are authored by the bot even though your normal remote uses SSH.)
- `gh auth login` once for your human account; bot commands override via `GH_TOKEN`.
- `.github/workflows/label-bot-prs.yml` auto-labels PRs authored by any Bot account.

Token minting requires `openssl`, `curl`, `jq`. Tokens expire after ~1 hour; `bot-env.sh`
mints a fresh one each invocation. Secrets must never be committed.
